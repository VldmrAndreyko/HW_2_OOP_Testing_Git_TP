## Система для управления рецептами

Это консольное приложение, которое позволяет создавать блюда, добавлять их в рецепты, масштабировать порции и генерировать список покупок.

## Установка

Чтобы развернуть проект на своем компьютере, выполните следующие шаги:

1. git clone https://github.com/VldmrAndreyko/HW_2_OOP_Testing_Git_TP
2. cd hw2_tp
3. pip install -r requirements.txt
